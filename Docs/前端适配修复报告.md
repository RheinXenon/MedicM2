## 一、问题描述

系统改造实现了科室隔离的知识库架构后，前端代码仍使用旧的全局知识库API，导致运行时错误：

```
AttributeError: 'AgentHospital' object has no attribute 'case_base'
```

**根本原因**：
- 旧架构：`hospital.case_base` 和 `hospital.experience_base`（全局共享）
- 新架构：`hospital.department_case_bases` 和 `hospital.department_experience_bases`（科室隔离）

## 三、关键技术点

### 3.1 科室名称映射

由于知识库使用科室ID（如 `cardiology`）作为key，但前端显示需要中文名称（如"心脏科"），需要建立映射关系：

```python
dept_name = next(
    (d['name'] for d in hospital.departments if d['id'] == dept_id),
    dept_id  # 如果找不到，使用ID作为fallback
)
```

### 3.2 数据聚合

所有原本访问全局知识库的地方，都需要改为遍历所有科室并聚合：

```python
# 统计总数
total_cases = sum(len(cb) for cb in hospital.department_case_bases.values())

# 聚合详细数据
all_cases = []
for case_base in hospital.department_case_bases.values():
    all_cases.extend(case_base.cases)
```

### 3.3 空值处理

有些科室可能没有病例或规则，需要妥善处理：

```python
if dept_stats:
    for dept, count in sorted(dept_stats.items(), key=lambda x: x[1], reverse=True):
        md += f"- **{dept}：** {count} 个案例\n"
else:
    md += "暂无案例\n"
```
