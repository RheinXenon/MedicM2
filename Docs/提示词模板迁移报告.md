# 提示词模板迁移报告

## 概述
根据代码冗余分析报告的建议，将项目中所有内联的提示词迁移到 `utils/prompt_templates.py` 统一管理，实现提示词的集中化、模块化管理。

## 迁移范围

### 1. 新增提示词模板（utils/prompt_templates.py）

#### 护士Agent模板
- **NURSE_TRIAGE_TEMPLATE**: 分诊提示词模板
- **NURSE_EXAMINATION_TEMPLATE**: 医学检查报告生成模板

#### 医生Agent模板
- **DOCTOR_DIAGNOSIS_WITH_KNOWLEDGE_TEMPLATE**: 医生诊断提示词模板（带病例库和经验库支持）

#### 经验库模板
- **EXPERIENCE_RULE_GENERATION_TEMPLATE**: 从失败案例生成经验规则的模板

#### 病人Agent模板
- **PATIENT_SYMPTOM_DESCRIPTION_TEMPLATE**: 病人症状描述模板

### 2. 修改的文件

#### agents/evolving_doctor_agent.py
- **修改内容**: 
  - 导入改为 `DOCTOR_DIAGNOSIS_WITH_KNOWLEDGE_TEMPLATE`
  - 将第160-200行的内联提示词替换为模板调用
- **效果**: 减少约40行冗余代码

#### agents/nurse_agent.py
- **修改内容**:
  - 新增导入 `NURSE_TRIAGE_TEMPLATE, NURSE_EXAMINATION_TEMPLATE`
  - 第127-155行：分诊提示词改用模板
  - 第233-262行：检查报告提示词改用模板
- **效果**: 减少约60行冗余代码

#### knowledge/experience_base.py
- **修改内容**:
  - 新增导入 `EXPERIENCE_RULE_GENERATION_TEMPLATE`
  - 第237-263行：经验规则生成提示词改用模板
- **效果**: 减少约30行冗余代码

#### agents/patient_agent.py
- **修改内容**:
  - 新增导入 `PATIENT_SYMPTOM_DESCRIPTION_TEMPLATE`
  - 第107-121行：症状描述提示词改用模板

## 使用方式

### 导入模板
```python
from utils.prompt_templates import (
    NURSE_TRIAGE_TEMPLATE,
    NURSE_EXAMINATION_TEMPLATE,
    DOCTOR_DIAGNOSIS_WITH_KNOWLEDGE_TEMPLATE,
    EXPERIENCE_RULE_GENERATION_TEMPLATE,
    PATIENT_SYMPTOM_DESCRIPTION_TEMPLATE
)
```

### 使用模板
```python
# 使用 format 方法填充参数
prompt = NURSE_TRIAGE_TEMPLATE.format(
    patient_name=patient.name,
    patient_age=patient.age,
    patient_gender=patient.gender,
    chief_complaint=complaint,
    symptoms_text=symptoms,
    department_list=dept_list
)
```
