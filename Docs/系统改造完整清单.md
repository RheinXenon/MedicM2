## 🔧 关键API变更

### AgentHospital

```python
# 旧API (已弃用)
hospital.case_base              # 全局病例库
hospital.experience_base        # 全局经验库

# 新API (当前使用)
hospital.department_case_bases[dept_id]        # 科室病例库
hospital.department_experience_bases[dept_id]  # 科室经验库
hospital.get_department_stats()                # 获取科室统计
```

### 知识库类

```python
# MedicalCaseBase / ExperienceBase

# 旧方式
case_base = MedicalCaseBase(storage_path="./knowledge/case_base")

# 新方式 (推荐)
case_base = MedicalCaseBase.get_instance(
    storage_path="./knowledge/case_base",
    department_id="cardiology"  # 指定科室ID
)
```

### NurseAgent

```python
# 新增方法
nurse.get_triage_stats()           # 获取分诊统计
nurse._map_department_name(name)   # 别名映射
```

## 🚀 使用指南

### 1. 数据迁移（首次使用）

如果有历史数据需要迁移：

```bash
# 运行迁移脚本
python migrate_knowledge_base.py

# 确认迁移
# 输入: yes

# 查看迁移报告
cat migration_report_*.json
```

### 2. 启动系统

```bash
# 启动前端界面
python start_hospital.py

# 或直接运行Streamlit
streamlit run frontend/app.py
```

### 3. 运行测试

```bash
# 运行所有测试
python test_agent_hospital.py

# 运行特定测试
python test_agent_hospital.py --test evolution
```

- 改造总览：`Docs/系统改造实施报告.md`
