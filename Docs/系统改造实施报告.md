## 一、改造概述

### 1.1 改造目标

本次改造旨在实现以下三大核心目标：

1. **科室内闭环演化**：让每个科室独立累积病例库与经验库，符合参考论文的训练范式
2. **分诊路径一致性**：确保护士推荐的科室始终与系统配置匹配，避免错配导致的fallback
3. **业务覆盖扩充**：扩展可用科室以涵盖常见疾病谱，支撑分诊与训练规模化

### 1.2 关键痛点解决

| 痛点 | 原因 | 解决方案 |
|------|------|---------|
| 演化信号稀释 | 全院共享病例库/经验库 | 为每个科室创建独立存储，实现数据隔离 |
| 分诊错配 | LLM返回未配置科室 | 增强提示词约束+别名映射+合法性校验 |
| 科室覆盖不足 | 仅5个科室 | 扩展至18个科室，覆盖常见就诊场景 |

# 核心改动示例
def __init__(
    self, 
    storage_path: str = "./knowledge/case_base",
    department_id: str = None
):
    self.department_id = department_id
    if department_id:
        self.storage_path = os.path.join(storage_path, department_id)
    else:
        self.storage_path = storage_path
    os.makedirs(self.storage_path, exist_ok=True)

##### 2.1.3 修改 `AgentHospital`

**文件**: `simulation/agent_hospital.py`

**关键改动**：
- 为每个科室创建独立的病例库和经验库实例
- 使用工厂方法 `get_instance()` 避免重复加载
- 医生Agent注入科室专属知识库

```python
# 为每个科室创建独立知识库
for dept in self.departments:
    dept_id = dept['id']
    case_base = MedicalCaseBase.get_instance(
        storage_path=case_base_path,
        department_id=dept_id
    )
    experience_base = ExperienceBase.get_instance(
        storage_path=experience_base_path,
        department_id=dept_id
    )
    
    self.department_case_bases[dept_id] = case_base
    self.department_experience_bases[dept_id] = experience_base
```

**效果**：
- ✅ 医生只能访问本科室的病例和经验
- ✅ 跨科室数据完全隔离
- ✅ 每个科室独立演化

#### 2.2.3 增强分诊校验

**文件**: `agents/nurse_agent.py`

**新增功能**：

1. **别名映射**
```python
def _build_alias_map(self) -> Dict[str, str]:
    """构建科室别名到标准名称的映射"""
    alias_map = {}
    for dept in self.departments_knowledge:
        standard_name = dept['name']
        # 标准名称映射到自己
        alias_map[standard_name] = standard_name
        # 添加所有别名
        for alias in dept.get('department_aliases', []):
            alias_map[alias] = standard_name
    return alias_map
```

2. **合法性校验**
```python
# 合法性校验和别名映射
validated_depts = []
for dept_name in triage_result.get('recommended_departments', []):
    mapped_dept = self._map_department_name(dept_name)
    if mapped_dept:
        validated_depts.append(mapped_dept)
    else:
        # 越界：推荐了不存在的科室
        self.triage_stats['out_of_range_count'] += 1
```

3. **回退机制**
```python
# 如果所有推荐都无效，使用关键词匹配结果
if not validated_depts:
    self.triage_stats['fallback_count'] += 1
    if department_scores:
        validated_depts = [department_scores[0]['department']]
```

4. **分诊统计**
```python
self.triage_stats = {
    'total_triages': 0,
    'out_of_range_count': 0,  # 越界次数
    'fallback_count': 0  # 回退到关键词匹配的次数
}
```

**效果**：
- ✅ 分诊越界率可监控
- ✅ 自动将别名映射到标准名称
- ✅ 确保所有推荐科室都在系统配置中

### 2.3 里程碑 M3：数据迁移

#### 2.3.1 迁移脚本

**文件**: `migrate_knowledge_base.py`

**功能**：
1. 自动备份原有数据（添加`_backup`后缀）
2. 按科室字段将病例分类到子目录
3. 按科室字段将经验规则分类到子目录
4. 清理根目录，未识别科室移至`_unmigrated`
5. 生成详细迁移报告

**使用方法**：
```bash
# 标准迁移
python migrate_knowledge_base.py

# 指定路径
python migrate_knowledge_base.py \
  --case-base ./knowledge/case_base \
  --experience-base ./knowledge/experience_base \
  --config ./config/departments.json

# 试运行（不实际修改）
python migrate_knowledge_base.py --dry-run
```

**迁移流程**：
```
1. 备份原有数据
   ├── case_base -> case_base_backup
   └── experience_base -> experience_base_backup

2. 遍历病例文件
   ├── 读取 department 字段
   ├── 映射到科室ID
   └── 移动到 {dept_id}/ 子目录

3. 遍历规则文件
   ├── 读取 department 字段
   ├── 映射到科室ID
   └── 移动到 {dept_id}/ 子目录

4. 清理未识别文件
   └── 移动到 _unmigrated/ 子目录

5. 生成迁移报告
   └── migration_report_YYYYMMDD_HHMMSS.json
```

## 四、关键技术改进

### 4.1 架构层面

```
改造前：
AgentHospital
  └── 全局病例库（共享）
  └── 全局经验库（共享）
  └── 所有医生访问相同数据

改造后：
AgentHospital
  ├── 心脏科病例库 (隔离)
  │   └── 心脏科医生专属
  ├── 心脏科经验库 (隔离)
  ├── 神经科病例库 (隔离)
  │   └── 神经科医生专属
  ├── 神经科经验库 (隔离)
  └── ... (18个科室独立演化)
```

### 4.2 数据隔离保证

1. **物理隔离**：不同科室数据存储在不同目录
2. **逻辑隔离**：医生Agent创建时绑定科室专属知识库
3. **访问控制**：无法跨科室访问数据

### 4.3 性能优化

1. **缓存机制**：类级别缓存避免重复磁盘IO
2. **延迟加载**：仅在首次访问时加载科室数据
3. **内存索引**：病例和规则建立内存索引加速检索
